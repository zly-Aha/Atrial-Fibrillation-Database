# Peter Charlton Datasets

## 基本信息

| 字段 | 内容 |
| --- | --- |
| 官方链接 | https://peterhcharlton.github.io/info/datasets |
| 类型 | 数据集汇总索引 |
| 覆盖信号 | ECG、PPG、呼吸、血压、加速度等 |
| 许可 | 因数据集而异 |
| 访问方式 | 各数据集官方页面 |

## 页面内容

该页面汇总了生物医学信号处理研究中常用的公开数据集，包含 PPG 与 ECG 两类主要资源，例如 CapnoBase、MESA、MIMIC、PPG-DaLiA、WESAD、CinC 2017 Challenge 等。页面同时给出信号类型和数据采集场景说明，适合用于检索和选择合适的数据源。

## 使用要点

- 该页面本身是索引，不是单一数据集。
- 每个条目对应不同的数据规模和许可条款。
- 下载和使用前需进入对应数据集页面确认访问条件。
- 引用时引用具体数据集的原始论文，而不是只引用索引页面。
